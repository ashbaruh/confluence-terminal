# Confluence Terminal

מערכת ניתוח אישית: סורקת כל ערב את S&P 500, מניות מובילות בת"א וקריפטו, מדרגת כל נכס (ציון 0–100 + כיוון), בוחרת 5 המלצות למסחר הבא, ועוקבת אחרי כל המלצה מול קבוצת ביקורת אקראית ומול השוק. עלות הפעלה: ‎$0 (GitHub Actions + GitHub Pages + Yahoo Finance).

## התקנה (פעם אחת, ~10 דקות)

1. **Settings → Pages → Source:** בחר `GitHub Actions`.
2. **Settings → Actions → General → Workflow permissions:** בחר `Read and write permissions` → Save.
3. **Actions → Daily scan → Run workflow.** ההרצה הראשונה לוקחת 10–15 דקות (הורדת 6 שנות נתונים + בדיקה היסטורית).
4. כתובת הדף: `https://<username>.github.io/<repo>/` (מופיעה גם ב-Settings → Pages).

מכאן זה רץ לבד כל ערב בימים א'–ה' (01:15 שעון ישראל, אחרי סגירת וול סטריט).

## ניתוח לפי דרישה (אופציונלי)

לסימול שלא בסריקה: צור טוקן ב-GitHub → Settings → Developer settings → Fine-grained tokens → גישה לריפו הזה בלבד → הרשאה **Actions: Read and write**. הדבק אותו בגלגל השיניים בדף. הטוקן נשמר רק בדפדפן שלך.
בלי טוקן: Actions → Analyse one symbol → Run workflow → הקלד סימול.

## איך זה עובד

| שלב | מה קורה |
|---|---|
| ציון | מגמה (25%), חוזק יחסי מול כל הנכסים (25%), פריצת שיא/שפל 20 יום (20%), RSI (10%), נפח (10%), מצב השוק הכללי (10%) |
| כיוון | ציון ≥ 60 → למעלה / למטה; אחרת ניטרלי |
| עסקה | כניסה בפתיחה של יום המסחר הבא · סטופ 1.5 ATR · יעד 3 ATR · יציאה בסגירה אחרי מקסימום ימי החזקה |
| הצלחה היסטורית | כמה מהסיגנלים הקודמים של אותו נכס, באותו כיוון, הסתיימו ברווח (רק עסקאות בלתי תלויות, רק מידע שהיה ידוע באותו יום) |
| בחירת 5 | דירוג = ציון + אחוז הצלחה היסטורי; נכס שכבר מוחזק לא נבחר שוב |
| אופק החזקה | 1 / 5 / 10 ימים — נבחר אוטומטית לפי הבדיקה מחוץ למדגם |
| שורט | נכלל בהמלצות רק אם הבדיקה מצאה לו יתרון מול אקראי; אחרת מוצג כאזהרה |
| מעקב | כל המלצה נכתבת ל-`state/picks_history.json` ונשמרת ב-git לפני פתיחת המסחר — אי אפשר לערוך בדיעבד |

הגדרות (משקלים, סטופ/יעד, עמלות) — `engine/config.py`.
